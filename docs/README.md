## **Прямоугольник**

### [**rectangle.py**](../rectangle.py)

#### **area(a, b) — площадь прямоугольника**

Принимает стороны `a` и `b`, возвращает площадь прямоугольника по формуле `a · b`.  
`a` — первая сторона прямоугольника.  
`b` — вторая сторона прямоугольника.

~~~
print(area(3, 4))
~~~

- Выводит `12`

~~~
print(area(5, 2))
~~~

- Выводит `10`

#### **perimeter(a, b) — периметр прямоугольника**

Принимает стороны `a` и `b`, возвращает периметр прямоугольника по формуле `2 · (a + b)`.  
`a` — первая сторона прямоугольника.  
`b` — вторая сторона прямоугольника.

~~~
print(perimeter(3, 4))
~~~

- Выводит `14`

~~~
print(perimeter(5, 2))
~~~

- Выводит `14`

## **Квадрат**

### [**square.py**](../square.py)

#### **area(a) — площадь квадрата**

Принимает сторону `a`, возвращает площадь квадрата по формуле `a · a`.  
`a` — сторона квадрата.

~~~
print(area(4))
~~~

- Выводит `16`

~~~
print(area(7))
~~~

- Выводит `49`

#### **perimeter(a) — периметр квадрата**

Принимает сторону `a`, возвращает периметр квадрата по формуле `4 · a`.  
`a` — сторона квадрата.

~~~
print(perimeter(4))
~~~

- Выводит `16`

~~~
print(perimeter(7))
~~~

- Выводит `28`

## **Треугольник**

### [**triangle.py**](../triangle.py)

#### **area(a, h) — площадь треугольника**

Принимает основание `a` и высоту `h`, возвращает площадь треугольника по формуле `a · h / 2`.  
`a` — основание треугольника.  
`h` — высота треугольника.

~~~
print(area(6, 3))
~~~

- Выводит `9.0`

~~~
print(area(10, 5))
~~~

- Выводит `25.0`

#### **perimeter(a, b, c) — периметр треугольника**

Принимает стороны `a`, `b`, `c`, возвращает периметр треугольника как их сумму.  
`a` — первая сторона треугольника.  
`b` — вторая сторона треугольника.  
`c` — третья сторона треугольника.

~~~
print(perimeter(3, 4, 5))
~~~

- Выводит `12`

~~~
print(perimeter(6, 8, 10))
~~~

- Выводит `24`
